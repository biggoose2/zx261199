# 果冻蛙瓶 · 美术素材生成清单（合并版）

给 Codex 的任务：按下表生成 12 张图（其中 11 张是多物体拼图），再把拼图切成单张素材，全部保存到仓库的 `assets/` 目录。机器可读版本见同目录 `assets.csv`。

## 生成规则

1. 使用 OpenAI 图像接口（`gpt-image-1` 或更新的图像模型），`quality=high`，`output_format=png`，`size` 取「尺寸」列；「背景」为透明时设 `background=transparent`，否则 `background=opaque`。
2. prompt = `STYLE` + 本行「提示词」。
3. 整图按「整图文件名」保存到 `assets/sheets/`（`bg_room.png` 直接放 `assets/`）。
4. **切图**：把拼图按「网格」列（行×列）等分成格子，按「切出的文件」列的顺序（从左到右、从上到下）逐格裁切，去掉四周多余的透明边（保留 4px 余量），保存为 `assets/<名字>.png`。如果某个物体越过了格子边界被切坏，就改用透明区域连通块来定位该物体；仍然不行就重新生成整张。
5. **自检**：透明图四角像素 alpha 为 0；每个物体完整、没有被裁切；画面里没有文字；格子数量和顺序与表格一致。不合格的整张重新生成（最多 3 次），最后列出仍有问题的文件。
6. 成对的物体（如灯的开/关、白天/夜晚窗户、礼盒开/关）画在同一张图里，确保造型一致，请检查两者除了状态外是否一样。
7. 先生成 P1，再生成 P2。只新增 `assets/` 里的图片，不修改任何代码文件。

### STYLE（所有提示词的前缀）

```
这是横屏手机休闲游戏《果冻蛙瓶》的美术素材（主角是半透明果冻质感的圆滚滚小青蛙）。统一风格：温馨可爱的卡通3D渲染风，像高品质休闲手游的道具图标，造型圆润饱满，材质柔和有轻微光泽，边缘干净利落；配色以奶油粉、蜜桃色、暖原木色、奶白色为主，点缀薄荷绿和香槟金，饱和度适中、温暖柔和；暖色柔光，主光从左上方照来；正面平视并略微俯视约10度，能看到物体顶面一点点，没有夸张透视；图中不要出现任何文字、字母、数字和水印。
```
