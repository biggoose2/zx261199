# 果冻蛙瓶 Jelly Frog

单文件 three.js 小游戏，直接用浏览器打开 `jellyfrog.html` 即可（需联网加载 three.js）。

## 玩法
- **拖动甩飞**；双指拉长到爆开（软塌塌更能拉）
- **合成**：同色、同大小的蛙挤在一起会长大一级；偶尔变异出稀有/传说款或新体型，3 秒内连续合成音调会一路升高
- **体型**：普通 / 圆滚滚（弹、会滚）/ 肥胖（落地噗一声、肚子抖）/ 软塌塌（摊成一滩）。集齐一种颜色的 4 种体型，图鉴镶金边
- **撸蛙**：从空白处按下，在蛙身上来回滑动；撸满后冒爱心，合成更容易变异
- **捏扁**：按住蛙不动，越压越扁，松手「啵嘤」弹飞
- **装瓶**：点右下角「装瓶」，罐子掉下来；点蛙它会自己跳进去（再点瓶里的蛙会跳出来），拖到瓶口附近松手会被吸进去；「封瓶」收进展柜，「算了」放回桌上
- **工具**：点选切换模式，或直接把工具从底栏拖到桌上用一次

## 房间玩法（新）
- 房间全部 3D 建模：粉墙护墙板、木地板、隔板、梯子、藤蔓、壁灯、挂钟、拱窗、彩旗、秋千、蹦床、豆袋沙发
- **性格**：暴躁（拿棒子敲人）、勤劳（拖地、把掉下的摆件搬回隔板）、懒洋洋、胆小（被敲会逃）、社牛（找人贴贴）、调皮、夜猫子；点一下蛙能看到它的性格
- **皮肤能力**：长按牛奶/果汁类的蛙会喷出来并收集「材料」；珍珠奶茶喷珍珠；柠檬、橘子会酸到旁边的蛙；可乐摇晃后变火箭；火焰/熔岩蛙能融冰
- **开关灯**：点壁灯；全关就是夜晚，窗外换星空，夜光类的蛙会发光，不是夜猫子的蛙去睡觉
- **重力**：歪手机时蛙、隔板上的摆件、秋千、钟摆都会跟着动
- **布置**：点「布置」后拖动家具，下面的名字可以收起/摆出

## 文件
- `jellyfrog.html`：源码，UI 图片引用 `assets/` 目录（需要放在网页服务器上打开）
- `dist/jellyfrog.html`：单文件版，图片已内嵌，双击即可打开；改完源码后运行 `python3 tools/build_standalone.py` 重新生成
- `art/`：美术素材清单与原图存档
